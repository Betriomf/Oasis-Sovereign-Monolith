\section{Monotonic Gap Contraction and State Preparation}
Following the requirement for monotonic distance indicators (\texttt{arXiv:2611.34853}), geometric reachability bounds (\texttt{arXiv:2611.22547}), and explicit initial-preparation dependence (\texttt{arXiv:2611.12328}), consider a discrete relaxation process bounded above by $S_{\max} = \ln(10) \approx 2.302585$:
\begin{equation}
S(t+1) = S(t) + k_{\mathrm{fold}}\bigl(S_{\max} - S(t)\bigr), \qquad 0 < k_{\mathrm{fold}} < 1.
\end{equation}
The residual gap $\Delta(t) = S_{\max} - S(t) = (1 - k_{\mathrm{fold}})^t \Delta(0)$ contracts monotonically. Whenever $S_{\mathrm{cold}}(0) \le S_{\mathrm{hot}}(0) \le S_{\max}$, the initial remaining gap satisfies $\Delta_{\mathrm{hot}}(0) \le \Delta_{\mathrm{cold}}(0)$, so the higher-initialized preparation enters any threshold $\Delta(t) \le \varepsilon$ in no more discrete steps than the lower-initialized preparation, echoing logical-information exposure dynamics in monitored discrete cycles (\texttt{arXiv:2611.16479}).
