## 1. Verificación Soberana de Licencias (Token-Gating)

* **Validación Local:** El cliente de escritorio verifica la posesión del token de utilidad mediante firmas criptográficas asimétricas, eliminando servidores de autenticación centralizados.
* **Activación de Capa 0:** La posesión del token desbloquea el enrutamiento determinista ($\pi/\phi$) y el confinamiento térmico a $P \le 5.39	ext{W}$.
